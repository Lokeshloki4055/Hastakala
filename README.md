# Hasta Kala Shop

## Android App Development using GenAI

**Hasta Kala Shop** is an Android-based shopping application designed for promoting and selling handmade and traditional craft products. The app helps local artisans showcase their handmade items online and allows customers to browse, search, and purchase unique craft products easily.

The term **Hasta Kala** represents handmade art or hand-crafted products. This project focuses on supporting artisans by giving them a digital platform to reach more customers.

---

## Project Overview

Hasta Kala Shop is an e-commerce Android application where users can explore handmade products such as:

- Paintings
- Pottery items
- Handmade jewelry
- Wooden crafts
- Home decor items
- Bags and accessories
- Traditional art products

The application uses **Generative AI** features to improve the shopping experience by generating product descriptions, helping users search products, suggesting items, and supporting customers through AI-based assistance.

---

## Objectives

- To create an Android shopping platform for handmade craft products.
- To support local artisans by providing an online selling platform.
- To use Generative AI for product description generation and smart recommendations.
- To make product browsing and ordering simple for customers.
- To improve customer support using an AI chatbot.

## Key Features

- User registration and login

- AI-generated product descriptions

---

## Role of GenAI

Generative AI is used in this project to make the application smarter and more user-friendly.

### 1. Product Description Generation

When a seller uploads basic product details, GenAI can automatically generate a clear and attractive product description.

### 2. Smart Search

Users can search products using simple natural language, such as:

> Show me handmade wall decoration items

The app can understand the user’s request and show relevant products.

### 3. Product Recommendation

GenAI can suggest similar or related products based on the user's interest and browsing behavior.

### 4. AI Chatbot Support

An AI chatbot can help users with product information, order-related questions, payment help, and delivery details.

### 5. Seller Content Support

Sellers can generate product titles, captions, and promotional content using GenAI.

## Methodology

1. Requirement analysis was done to understand the needs of users and artisans.
2. UI screens were designed using XML in Android Studio.
3. Firebase was used for authentication, database, and image storage.
4. Product listing, cart, and order features were implemented.
5. GenAI features were added for product description generation and chatbot support.
6. The app was tested for basic functionality and user experience.
